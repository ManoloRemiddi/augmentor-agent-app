# Install Augmentor Agent

Use the [complete Desktop + Browser installation guide](COMPLETE-INSTALL.md) for the current Debian 13 amd64 preview, including required plugins and optional voice/memory engines.

[Download the complete release](https://github.com/ManoloRemiddi/augmentor-agent-app/releases/tag/v0.2.9-complete-preview.1).

The [Fedora experimental package](FEDORA.md) and [legacy Browser 0.1.32](https://github.com/ManoloRemiddi/augmentor-dsh-extension-plugin/releases/tag/v0.1.32) are separate older distributions. Do not mix their runtimes with the complete bundle.

For existing users, read [desktop deployments](DESKTOP-DEPLOYMENTS.md). The fresh installer preserves existing installations and requires a reviewed migration.
